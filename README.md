# MV Forge

**曲・歌詞・画像を持ち込むと、1曲まるごとのアニメMV / リリックビデオを準量産できる合成エンジン。**

Next.js + Remotion 製のローカルアプリです。ブラウザのGUIで編集し、プレビューと書き出しは同一のRemotionコンポーネントで描画されるため「見たまま」がmp4に焼けます。

> 思想は **B型合成エンジン**: 素材（曲・画像・朗読）は外部で完成させて持ち込む。AIは提案者、決定者は常に人間。

## 特徴

- **LRCが背骨**: 曲（またはボーカルステム）＋正解歌詞から歌詞タイミングを自動整列（ElevenLabs Scribe）。単語レベル同期のカラオケ塗り・文字送り演出まで自動で音に乗る
- **エフェクト図鑑 500本超**: カメラワーク・切替・オーバーレイ・WebGLレンズフレア・歌詞アニメ・タイトル/テロップ・装飾を内蔵（`/effects` で全カタログをプレビュー）。すべて自作実装で、コードごと改造できる
- **AI参謀（任意）**: Claude / Codex / Gemini のCLIどれか1つがあれば、絵の配役・カメラ・切替・歌詞演出を曲の実測データ（BPM・小節・サビ検出）込みで一括提案。頭脳はドロップダウンで切替可。⌘Zで丸ごと戻せる
- **ビート検出**: 拍・小節・サビを自己相関で実測し、吸着・演出強弱・波形表示に反映
- **縦型ショート**: 本編から範囲を選ぶだけで9:16ショートを派生（しおり方式＝本編の修正が自動反映）
- **書き出しプリセット**: YouTube 1080p / X 720p / 縦型9:16。区間だけのドラフト書き出しも可

## 動作要件

- Node.js 20+ / pnpm
- **ffmpeg / ffprobe**（曲の長さ計測・波形・ビート検出）
- macOSで開発・動作確認（他OSは未検証）

任意（無くても編集・書き出しは動きます）:

| 機能 | 必要なもの |
|---|---|
| AI参謀・一括提案・口頭修正 | `claude`（Claude Code）/ `codex`（Codex CLI）/ `agy`（Antigravity CLI）のいずれか。複数あれば画面で切替可 |
| ①LRC自動生成（歌詞の自動整列） | `.env.local` に `ELEVENLABS_API_KEY` |
| 🎬 画像→動画（i2v） | `.env.local` に `FAL_KEY` |
| 🎙️ 朗読生成（プロローグ） | `.env.local` に `FISH_AUDIO_API_KEY` |

※ 画像そのものの生成は外部ツール（Midjourney等）で行い `images/` に入れる運用が基本です。各APIの利用料は自己負担です。

## セットアップ

```bash
pnpm install
pnpm dev        # → http://localhost:3000
```

## 使い方（1本の流れ）

1. トップページでプロジェクト作成 → `projects/<名前>/` に `song.mp3` と `images/`（持込画像）を入れる
2. **セットアップ** — LRC貼り付け、または「LRC自動生成」（曲＋正解歌詞 → 9割自動）
3. **テロップ様式** — 縦書き/横書き・フォント・色を作品全体で1回決める
4. 歌詞表を上から、素材帯から**画像をD&D** → 区間が自動で色分けされる
5. **AIレコメンド**（任意）— 絵の配役＋演出を全シーン提案 → そのまま反映（⌘Zで復帰）
6. 詳細設定で微調整 — オフセット（小節頭に吸着）・エフェクトのつまみ・ショット割り
7. プレビュー確認 — 行クリック=頭出し、Space=再生/停止
8. **書き出し** — まず「選択区間＋ドラフト画質」で試し刷り → OKなら本番画質

## プロジェクト構造

```
projects/my-mv-01/
  ├─ song.mp3          ← 曲
  ├─ vocals.mp3        ← （任意）ボーカルステム。LRC自動生成の精度が上がる
  ├─ lyrics.lrc        ← （任意）手持ちのLRC。無ければ自動生成
  ├─ images/           ← 持込画像
  ├─ exports/          ← 書き出したmp4
  ├─ beats.json        ← ビート検出結果（GUIから生成）
  └─ project.json      ← 設計図（このツールが管理）
```

量産はフォルダごとコピー → 曲・画像・歌詞を差し替え、が基本動線です。

## エフェクトを増やす

`lib/effects-meta.ts` にメタデータ、`remotion/effects/` にコンポーネントを1個ずつ追加します（`description` はAI参謀が読みます）。既存部品の実装がそのままサンプル集です。
